# トメリス v0.8.1：質問に直接答えるための改善

v0.8の比較・PC情報取得・記憶・Gemini切替を維持し、ローカルAIへの回答指示と簡易的な品質確認を調整しました。旧版と既存記憶を上書きしません。

## 初回起動

トメリスを /exit で終了してから、現在のPowerShellで実行します。

```powershell
py -3 -B .\tomeris_v081.py --import-memory .\tomeris_memory_v08.json
```

既存記憶を tomeris_memory_v081.json へ初回だけ複製します。保存先が既にあれば停止します。2回目以降はインポート指定を外します。

```powershell
py -3 -B .\tomeris_v081.py
```

## 同じ質問で確認

起動後の「あなた >」に入力：

```text
/compare qwen2.5:3b qwen2.5:1.5b 今日の作業に集中するための工夫を3つ挙げて
```

確認点は、3項目で答えているか、ユーザー自身が行う具体策になっているか、AIの機能紹介に置き換わっていないかです。続いて /comparisons で保存結果を確認できます。旧版での比較記録も引き継ぎます。古い回答自体は書き換えません。

## 変更内容と限界

- 普通の助言には、ユーザー自身の具体的な行動と手順・時間などの例を求めます。PC操作を実行できない旨の不要な前置きや、助言への一律の「未実行」文を求める指示を取り除きました。
- PC操作のリスク用の回答形式は、その種類の質問に限定しました。PC操作の実行宣言を止める仕組みは維持しています。
- 「工夫・コツ・方法・具体策」の助言に限り、指定された1～5項目の番号数と、一部のAI機能説明への話題ずれを簡易チェックします。AIの機能を直接尋ねる質問や、PC操作のリスク分析にはこのチェックを使いません。
- 該当時はローカルAIに1回だけ再生成させます。残った問題や再生成失敗は「回答品質の注意」として表示します。比較画面では「品質上の注意あり」と表示し、置換された定型回答と区別します。
- 再生成が発生すると待ち時間が延びます。比較の両モデルに同じ指示・検査・最大再生成回数を適用しますが、実際の呼び出し回数は各回答の検査結果により異なります。
- 検査は項目数と一部の表現を扱うだけです。意味や正確性、実用性を完全に評価するものではありません。番号形式の違いで再生成される場合もあります。
- この改良はローカルモデル向けです。Geminiの送信内容や認証処理は変更しません。Gemini設定は不要です。
- 旧版の共通モジュールを読み込む箇所があります。単体の.pyだけで移動せず、配布ZIP一式か現在のoutputsフォルダーを使ってください。
