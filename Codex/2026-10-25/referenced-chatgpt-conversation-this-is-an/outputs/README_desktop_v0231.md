# トメリス v0.23.1：自動検索を標準に

起動時から「会話＋自動検索」を選択します。毎回モードを選ぶ必要はありません。起動時の挨拶にも、検索する場合の送信先と送信内容を表示します。

- 普段の相談や文章作成：通常のローカル会話。
- 天気・最新情報・ニュース・価格・「調べて」など：質問をBingへ送って検索。
- 「今日の天気は？」だけの場合：地域を尋ね、場所を推測しません。

現時点の自動切り替えはv0.23と同じキーワード判定です。あらゆる質問の意味を判断するものではありません。確実に検索したい場合は「検索して」と付けるか「ネット検索」を選べます。検索を使いたくない間は「会話」を選んでください。再起動すると自動検索に戻ります。

検索機能は試験版です。取得できない場合や無関係な結果が返る場合があります。記憶・過去会話は検索先へ送りません。その他の制約は README_desktop_v023.md を参照してください。

一時データの画面テストで、初期モード、通常会話への分岐、自動検索への分岐、地域確認、URL表示、通信失敗後の復帰を確認しました。外部通信とブラウザー起動は模擬です。既存の記憶・旧バージョンは変更していません。
