# v0.43 調査履歴
アプリを開き直すと反映されます。

「調査履歴を見せて」で最近の調査を確認できます。表示されたIDを使い、`/research-show ID`で過去の出典を表示、`/research-delete ID`でその履歴を削除できます。

一般資料調査の質問・出典名・URL・記録時刻・選択方法を最大100件保存します。100件を超えると古い履歴から除きます。本文・AI回答は保存しません。天気・地震などの専用機能は対象外です。

閲覧だけでは再検索しません。再調査するには質問を改めて入力してください。履歴はバックアップ・別フォルダー復元にも含まれます。旧バックアップも利用できます。

検証：249件のテスト成功。一時データと模擬ページで確認し、外部APIの実接続は今回未検証です。
