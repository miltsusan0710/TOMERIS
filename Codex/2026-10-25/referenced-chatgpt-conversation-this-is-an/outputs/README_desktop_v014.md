# トメリス v0.14：計画ごとの振り返り

1. トメリスを×で閉じ、デスクトップのアイコンから開き直します。
2. 「計画の履歴」で振り返りたい計画を選びます。
3. 「この計画の振り返りを書く」を押します。
4. できたこと・難しかったこと・次に変えることなどを自由に入力します（1〜2000文字）。
5. 「振り返りを保存」を押します。保存後は計画の履歴に表示されます。

例：小さく始められた。次も5分から取り組む。

再び同じ計画の振り返り画面を開くと、保存済みの内容を編集できます。
未保存の変更がある状態で閉じると確認します。保存に失敗した場合、入力内容は画面に残します。
振り返りは `tomeris_desktop_data/plan_reflections.json` に独立して保存します。書き直し前の文章もファイル内に保持し、画面には最新の文章を表示します。
計画・完了記録・会話の記憶は変更しません。振り返りをAIやGoogleへ送信する機能はありません。
