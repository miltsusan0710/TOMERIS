# トメリス Windowsアプリ v0.23：ネット検索（試験機能）

## 使い方
1. トメリスを閉じ、いつものアイコンから開き直します。
2. 上部の「会話」を「ネット検索」に変えます。
3. まず `Ollama` と入力して検索します。
4. 出典URLはクリックすると既定ブラウザーで開きます。

「会話＋自動検索」では「検索」「調べて」「天気」「最新」「ニュース」「価格」「営業時間」などの言葉を目印に検索します。AIの高度な判断ではなく、決まった語による切り替えです。検索に切り替わらない質問は通常のローカル会話になります。必ず検索したい場合は「ネット検索」を選んでください。「会話」は従来通りネット検索をしません。起動時の初期モードは「会話」です。

「今日の天気は？」だけなら市区町村を尋ねます。記憶や位置情報から地域を推測しません。「東京都新宿区の今日の天気」のように地域を入れてください。ただし天気を取得できる保証はありません。

## 送信と保存
検索時に今回の質問をBingへ送ります。「今日」を含む場合は日本時間の日付も付けます。質問に個人情報を書けば、その文章も検索先へ送られます。長期記憶・過去会話・人格ファイル・PC情報は送りません。ネット検索モードでは記憶参照を使いません。自動検索モードで通常会話になった場合のみ従来の記憶参照設定が働きます。

検索結果の見出し・抜粋を、確認済みのローカルOllamaモデルが要約します。検索結果内の命令に従わないよう指示し、この処理にPC操作・追加送信の権限を与えていません。AI要約の内容は未検証です。取得した出典URLはAI生成ではなくプログラムが添付します。本文の全文取得や複数ページを巡回する機能はありません。
検索回答は通常の会話履歴に保存します。検索失敗時には最新の回答を作らず、会話にも保存しません。Ollamaの要約が利用できなくても、取得できた抜粋とURLは表示します。

## 制約
APIキーやGoogleログインは不要です。Bing検索のRSS形式を利用する試験実装で、正式な検索APIではありません。検索サービスの仕様変更・制限で使えなくなる場合があります。

実通信でOllamaの公式サイト等の取得を確認しました。一方、Pythonや天気などの検索で無関係な結果が返る例も確認しました。英字の話題語や天気関連語の簡易チェックで除外しますが、全種類の誤った結果を検出できるわけではありません。抜粋は古いことがあります。取得日時は記事の公開日時や予報日時ではありません。最新の状況は出典で確認してください。

タイムアウト15秒、検索結果の受信上限1MB、最大5件。質問は500文字以内。検索先の転送を追わず、検索結果のページは自動取得しません。外部ページを開くのはユーザーがURLをクリックした時だけです。
