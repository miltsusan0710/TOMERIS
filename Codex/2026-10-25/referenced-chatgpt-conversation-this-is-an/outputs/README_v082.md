# トメリス v0.8.2

ローカルAIの助言を短くし、不確かな方法名や架空の出典を付け足さないよう回答指示を調整しました。v0.8.1の機能を維持し、新しい記憶ファイルを使用します。

現在のトメリスを /exit で終了し、outputs フォルダーのPowerShellで初回だけ実行してください。

```powershell
py -3 -B .\tomeris_v082.py --import-memory .\tomeris_memory_v081.json
```

既存記憶を tomeris_memory_v082.json へ複製します。保存先が存在すれば上書きせず停止します。2回目以降：

```powershell
py -3 -B .\tomeris_v082.py
```

起動後の確認：

```text
/compare qwen2.5:3b qwen2.5:1.5b 今日の作業に集中するための工夫を3つ挙げて
/comparisons
```

確認する点は、3項目・各1～2文程度・今の作業で実行できる行動・不要な方法名の追加がないことです。既存の比較記録は保持され、過去回答は修正されません。

変更：一般的な助言は短く、効果を保証せず、確信のない名称は平易な手順で説明するよう指示しました。「今日」「今すぐ」の質問では着手できる行動を優先します。以前の固定例を外し、同じ例への過度な引き寄せを抑えました。

「工夫・コツ・方法・具体策」の一部の質問に限り、従来の項目数・話題ずれ検査に加え、新しい「○○と呼ぶ」等の名称の付加と600字を超える回答を検出し、必要なら1回だけ再生成します。詳しい回答を求められた場合は長さを検査しません。質問に含まれる名称はこの理由で再生成しません。再生成後も問題が残る場合は注意付きで表示・保存します。正しい名称を検出する場合や、表現によって見逃す場合もあります。

これは外部資料を調べる事実確認ではありません。専門用語や回答の真偽を判定できず、医療等の効果も検証しません。検査通過は正確性の保証ではありません。Geminiの設定・通信・送信内容は変更せず、今回の改良はOllamaの通常会話と比較に適用されます。

2026-10-25、Windows上で48件の自動テストに合格（従来43件と追加5件）。モデル応答は模擬したため、実モデルでの改善は上記の質問で確認してください。
