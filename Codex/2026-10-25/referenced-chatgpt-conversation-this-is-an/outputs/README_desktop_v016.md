# トメリス v0.16：記憶・計画データのバックアップ

1. トメリスを×で閉じて開き直します。
2. 画面上部の「データ」を開きます。
3. 「記憶・計画のバックアップを保存…」を選びます。
4. 保存先を選び「保存」を押します。
5. 「バックアップを保存し、内容の一致を確認しました。」と表示されたら完了です。

同名のファイルは上書きしません。別の名前を指定してください。
保存先の選択を取り消した場合は、バックアップを作成しません。

## 含まれるデータ

- tomeris_memory.json：会話・長期記憶・成長ログ・比較記録など、デスクトップ版の記憶
- daily_plans.json：作成済みの計画
- plan_progress.json：完了チェック
- plan_reflections.json：振り返りとその更新記録

未作成の計画関連ファイルは含めません。ZIP内のmanifest.jsonに、含めたファイルのサイズとSHA-256、未作成のファイル名を記載します。
Google接続情報、アプリ本体、Ollamaモデル、人格ファイル、外部知識ファイルは含みません。外部知識ファイルへの参照が記憶に含まれる場合も、参照先のファイル本体は別途保管が必要です。

ZIPは暗号化されません。会話や個人の記録が含まれるため、自分が管理できる場所に保存してください。
今回はバックアップ作成機能です。アプリ内の復元ボタンはまだありません。

## 検証

既存機能を含む57件の自動テストが成功。
元データとのバイト単位の一致、ZIPの整合性、Google接続情報の除外、既存バックアップの保護、作成失敗時の処理、入力データの保持を確認しました。
一時データを使用した画面テストで、メニューからの保存・取消・保存中の操作制限・同名ファイルの拒否を確認しました。
実際の利用データのバックアップは、利用者が画面で保存先を選んだときに作成します。
