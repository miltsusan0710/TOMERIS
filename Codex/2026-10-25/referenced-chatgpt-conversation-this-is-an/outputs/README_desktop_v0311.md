# v0.31.1：天気の日付と地域の読み取り修正

「明日の荒川区の天気は？」を、地域「荒川区」、日付「明日」に分けて処理します。「荒川区の明日の天気は？」にも対応します。
地域の取得に失敗して「荒川区」と答え直した場合も、「明日」を保持します。

自動テスト162件成功。前後の日付表現と、地域確認に失敗した後の再入力を模擬APIで確認しました。今回、実際の天気予報の取得は行っていません。
トメリスを閉じて開き直してください。v0.31.1が目印です。会話の配置と既存データは維持します。
修正前の天気サービスは tomeris_weather_service_before_v0311.py に保存しています。
