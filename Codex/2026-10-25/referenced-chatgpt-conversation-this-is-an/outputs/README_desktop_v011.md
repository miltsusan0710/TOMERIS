# トメリス v0.11：今日の計画の完了チェック

## 使い方

1. 起動中のトメリスを×で閉じて、デスクトップのアイコンから開き直します。
2. タイトルの v0.11 を確認します。
3. 「今日の計画」を押すと、行動ごとのチェック欄が開きます。
4. 終わった行動にチェックすると自動で保存します。「保存済みです。」を確認してください。
5. チェックを外せば未完了に戻ります。完了数も画面に表示します。
6. 閉じて開き直してもチェック状態を復元します。

今日の計画がない場合は、この画面を閉じて「計画を作る」から作成してください。
日付は日本時間です。昨日の計画を今日に自動で移すことはありません。
同日に新しく計画を作ると、新しい計画は未完了から始まります。過去の計画と完了記録は残ります。
保存・読込中は操作を一時停止します。保存失敗時はチェック表示を元の状態に戻し、エラーを表示します。
日付や計画が変わった場合は「読み直す」を押してください。

## データと旧版

完了状態だけを `tomeris_desktop_data/plan_progress.json` に保存します。
チェック操作では既存の `daily_plans.json` や記憶ファイルを変更しません。
Googleの設定・ログインは不要です。Google連携は引き続き保留のままで利用できます。
旧版 v0.10 のコードは `tomeris_desktop_v010.py` に残しています。
