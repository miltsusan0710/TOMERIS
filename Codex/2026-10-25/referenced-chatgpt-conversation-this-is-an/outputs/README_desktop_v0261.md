# トメリス v0.26.1：無関係な引用による誤報告を停止

## 今回の誤り
「アイアンマンについて調べて」に対して、シャインマスカットやマンションの記事を引用し、「アイアンマンはアメリカの漫画家」と回答したのは誤りです。引用番号の存在は、説明を裏付ける証拠にはなりません。v0.26の検査では意味の一致を確認できていませんでした。

## 修正
- 調査報告のAI要約を停止しました。ローカルモデルが確認済みでも呼びません。
- 日本語の2文字部分一致を廃止。アイアンマンなどの対象名を省略せず照合します。
- アイアンマン／Iron Manなど、少数の明示した別表記だけを同じ対象として扱います。
- 表示する引用そのものに対象語が必要です。ページタイトルに対象語があるだけでは採用しません。隣の無関係な行も連結しません。
- 無関係な本文しかなければ、根拠不足として報告を停止します。
- 根拠を表示できた場合も「対象語が含まれる本文・原文」と明記します。内容の正しさや質問への十分性を検証したと誤解させません。

アプリを閉じ、いつものアイコンから開き直してください。デザイン、計算、天気、通常会話は維持します。すでに保存された過去の誤回答は自動で削除・改変していません。

## 制約
この修正は、正しい調査が必ず成功するようになるものではありません。検索先が無関係な結果を返す問題は未解決です。本文の一致判定を厳しくしたため、有用なページも採用できない場合があります。調査報告の日本語要約は、意味の裏付けを信頼できる形で検証できるまで停止します。通常会話のAI回答全般の正確性は保証していません。

URLを指定するときも対象名を入れてください。
例：`https://ollama.com/ Ollamaの機能を調べて`

## 検証
131件の自動テストが成功。ユーザーが提示した無関係なYahoo!本文、タイトルだけの一致、部分一致、隣接する無関係な行、根拠がない場合のモデル呼び出し禁止を確認しました。実画面でも同じ質問と誤った検索結果を再現し、無関係な引用・AIの説明を出さず停止することを確認しました。ユーザーの実データは検証に使用していません。

旧版のファイルは保持しています。ただしv0.26には今回の誤報告を起こす処理が残っているため、通常の起動先は修正版に変更しています。
