# トメリス v0.8.4：記憶の主体と保証の区別

初回は現在のトメリスを /exit で終了し、outputs のPowerShellで実行：

```powershell
py -3 -B .\tomeris_v084.py --import-memory .\tomeris_memory_v083.json
```

元の記憶は変更せず、tomeris_memory_v084.json へ複製します。既存の保存先があれば停止します。次回からはインポート指定を外してください。

```powershell
py -3 -B .\tomeris_v084.py
```

確認：

```text
/ask-memory 私の目標を教えて
今日の作業に集中するための工夫を3つ挙げて
```

「私の目標を教えて」など特定の目標照会は、Ollamaへ送らず長期記憶の原文とIDを表示します。記憶内の分類が「目標」、または本文に「目標」を含む記録から最大3件、各1000文字まで引用します。複数の主体が混ざっている可能性があるため、すべてを個人の目標とは断定しません。トメリスの目標であると明記された記録にはその区別を添えます。目標や判断原則は成果の保証を意味しない旨も示します。該当記録がなければ不明と返します。

対象は限定した照会表現です。「目標を達成する工夫」など通常の相談は引き続きAIが回答します。/compare はモデル比較なので原文照会への切替はしません。Geminiにもローカル記憶を送信しません。既存の使命質問の定型回答は維持しています。

ほかの記憶付き回答では、AIに渡す長期記憶をID・分類・原文付きにし、原文の主語を保つことと、判断原則を保証へ変換しないことを指示しました。これは一般的な意味理解の正確さを保証するものではありません。

保存記録そのものの真偽や矛盾は検証・修正しません。古い誤回答も履歴に残します。今回の確認で成功した引用回答は通常の会話履歴へ保存しますが、元の長期記憶は変更しません。人格・過去版・旧記憶の上書きも行いません。

Windows上で58件のテストに合格（従来53件＋新規5件）。主語を変えず原文を引用すること、モデルへの未送信、元データの不変、記録なし・複数主体、通常相談との区別を追加検証しました。一般回答の実モデル生成は未検証です。
