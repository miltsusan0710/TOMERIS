# v0.32：明後日の天気と会話の好み

## 天気
「明後日の荒川区の天気は？」と「荒川区の明後日の天気は？」に対応しました。明後日の場合は3日分の予報を要求し、日本時間の該当日の値を選びます。
「明日の荒川区の天気は？」の後に「明後日は？」と聞くと、直前に指定した地域を引き継ぎます。取得失敗後に地域を答え直しても日付を保持します。
対応日付は今日・明日・明後日です。現在地を取得する機能はありません。

## 会話の好みを覚える
通常の会話欄で次のように伝えられます。
- 今後は回答を短くして
- 今後は回答を詳しくして
- 会話の好みを教えて
- 会話の好みをリセット

明示した好みを長期記憶の「会話の好み」に保存し、次の通常会話のローカルAIへの指示へ反映します。再起動後も維持します。記憶画面でも内容と変更履歴を確認できます。
リセットは有効な好みを標準へ戻す操作で、過去の変更履歴を消去する操作ではありません。
これは話し方の好みを記憶する機能で、モデル自体の再訓練ではありません。一般的な訂正から知識を自動学習する機能はまだありません。AIの回答や検索記事をそのまま正しい知識として学習しません。天気・原文表示などの固定報告には好みを適用せず、Googleへの質問にも付加しません。
