# トメリス v0.8.3：短い指示と必要時だけの記憶参照

今回の診断を踏まえ、通常のローカル回答に渡す指示を短くし、重複した長い指示の追加をやめました。記憶の保存・一覧・検索・比較・PC情報・Gemini切替は維持します。

## 初回起動

トメリスを /exit で終了後、outputs フォルダーのPowerShellで実行：

```powershell
py -3 -B .\tomeris_v083.py --import-memory .\tomeris_memory_v082.json
```

旧記憶を tomeris_memory_v083.json に初回だけ複製します。旧版・旧記憶は変更せず、保存先が存在すれば停止します。次回からは：

```powershell
py -3 -B .\tomeris_v083.py
```

## 確認

まず通常会話で入力してください。

```text
今日の作業に集中するための工夫を3つ挙げて
```

次に記憶を使う質問：

```text
/ask-memory 私の目標を教えて
```

比較を試す場合：

```text
/compare qwen2.5:3b qwen2.5:1.5b 今日の作業に集中するための工夫を3つ挙げて
```

## 記憶の扱い

通常の独立した質問では、人格ファイル・知識資料・過去会話を自動で丸ごと追加しません。保存した記憶自体は削除せず、通常の会話の保存も続けます。

「記憶」「覚えて」「前回」「以前」「さっき」「先ほど」「前の話」「続き」「私の目標」「私の方針」「基本人格」「人格に沿」などを含む質問で、関連する長期記憶2件、成長ログ1件、知識資料1件を短く取り込みます。過去の会話を参照する表現がある場合のみ直近1往復を加えます。単なる「それは？」などでは検出できないため、「前の話の続き」と明示してください。

参照データは各フィールドで文字数を制限し、全体1600文字以内にします。上限超過時は最後に加えた種類のデータから省略します。キーワード検索のため、必要な記憶を必ず見つけられる保証はありません。

/ask-memory 質問 は記憶参照を明示します。Ollama専用で、Gemini選択中はローカルへの切替を案内します。Geminiには引き続き記憶を送りません。

独自の人格ファイル全体は通常回答へ自動追加しません。表示は /persona、人格を参照した回答には「基本人格に沿って」と指定してください（先頭600文字まで）。細かい独自ルールが必要な場合は質問にも明示してください。PC操作の依頼を止める処理、実行宣言・PCリスク検査は維持しています。

## 検証と限界

Windows上で53件成功（従来48件と新規5件）。通常質問で記憶検索・人格読取を行わないこと、記憶参照の制限、過去話題の判定、長い指示を重複追加しないこと、PCリスク用指示の限定、従来機能を確認しました。モデル回答は模擬したため、実際の速度・回答品質はユーザー環境で確認が必要です。診断Aと完全に同じ指示ではありません。

```powershell
py -3 -B -m unittest discover -s . -p 'test_v083*.py' -v
```

事実確認機能は追加していません。簡易チェックは正確性の保証ではありません。回答の修正生成が起きれば待ち時間が増えます。複数版を同時に使用すると、記憶はそれぞれ別々に蓄積します。

配布ZIPにはコードとテストだけを含め、個人の記憶JSON・知識資料は含めません。必要な共通モジュールも同梱するため、単一ファイルだけ移動せず一式を使用してください。
