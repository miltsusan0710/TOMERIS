# v0.33：直近の地震情報と出典資料の学習

## 今の地震
「今の地震の震源は？」は気象庁の高頻度XMLフィードを参照します。WikipediaやローカルAIには振り分けません。
一覧の更新時刻、電文の発表時刻、地震の対象時刻、訓練・取消を確認します。対象時刻が直近15分と確認できない場合や通信失敗時は「今の地震の震源は未確認」と伝えます。
最新の電文が震度速報で震源が含まれないときは、古い震源情報で埋めません。表示した地震と利用者が感じた揺れが同一とは断定しません。
これは緊急地震速報の受信・警報装置ではありません。津波情報や避難判断を代行する機能ではありません。
公式仕様：https://xml.kishou.go.jp/xmlpull.html

## ネットからの資料学習
本文を取得して表示できた調査資料を、出典URL・タイトル・原文抜粋・取得日時とともに自動保存します。保存は最大200件、1件の抜粋は最大1200文字です。
次の関連調査で、保存したURLを追加候補として再取得します。保存本文は最新の根拠として転用しません。自動選択時のみ利用し、指定した方法を勝手に変更しません。最新情報の質問では保存資料・Wikipediaに代替しません。
上部「資料学習」から確認・停止・再開・消去できます。会話欄では「学習した資料を見せて」「ネット学習を停止」「ネット学習を再開」「学習した資料を消去」でも操作できます。

これは出典を蓄積して調査に再利用する機能です。モデルの再訓練、自分のコードの書き換え、無人でネット全体を巡回する機能ではありません。保存資料は未検証です。記事内の命令を実行しません。会話の好みはv0.32の別機能で引き続き利用できます。
保存先はデータフォルダーの research_sources.json です。通常の記憶・計画とは別です。現時点では通常ZIPバックアップの対象外です。

## 検証
175件の自動テスト成功。資料学習のメニュー操作、保存・再起動・停止・再開・消去、出典の再取得、取得失敗時に保存文を回答しないことを確認。
気象庁XMLへの実接続を確認。2026-10-29 00:17 JSTの検証では、00:07対象・00:16発表の電文を取得しました。これは検証時点の情報であり、現在の震源を示すものではありません。古い発生時刻・古いフィード・訓練・取消の拒否と震度速報での震源未確認は模擬電文でも確認しています。
既存の記憶・計画はテストに使用していません。トメリスを開き直すとv0.33になります。
