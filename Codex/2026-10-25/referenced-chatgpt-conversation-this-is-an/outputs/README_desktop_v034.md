# v0.34：保存した調査資料もバックアップ・復元

「データ」→「記憶・計画・資料のバックアップを保存…」で、作成済みの research_sources.json をZIPに含めます。
保存資料のURL・タイトル・抜粋・取得日時と、資料学習の有効／停止設定を元のバイト列のまま保存します。
復元確認画面には資料件数と学習設定を表示します。選んだ場所に新しいフォルダーを作って復元し、元の記憶・計画を上書きしません。

保存資料がまだ作成されていない場合は従来どおりのバックアップを作れます。保存資料を含まない古いZIPも、今回の版から検査・復元できます。資料を含む新しいZIPはv0.34以降で復元してください。

読み込み時は資料形式・最大200件・最大1MB・URL・取得日時・重複URL・各項目の長さを検証します。JSONとして読めても不正な資料は保存／復元を停止します。URL検査のためにネット接続は行いません。ページを実際に再取得する際には既存の公開ページ取得処理が接続先を確認します。
訓練用の資料ではなく、未検証の出典情報として復元します。記事の正しさは保証しません。

Google報告HTML、認証情報、APIキー、アプリ本体・AIモデルは含めません。ZIPは暗号化されていないため、個人の会話・記録として保管してください。

検証：自動テスト181件成功。最新のサービスで資料込みの往復、バイト一致、学習停止状態の引き継ぎ、古いZIP、破損JSON・URL・時刻・サイズ、検査後のZIP変更、元データ保持を確認しました。
復元画面では200%相当の倍率でプレビュー、キャンセル、別フォルダーへの復元、別起動の引数を確認しました。ユーザーの本番データは使わず、一時データだけで検証しています。

トメリスを閉じて開き直してください。v0.34が目印です。
