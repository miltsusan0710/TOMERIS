# トメリス v0.18：会話履歴の検索

1. アプリを×で閉じ、デスクトップのアイコンから開き直します。
2. 左の「会話履歴」を押します。
3. 検索語を入力して「検索」またはEnterを押します。
4. 一覧の会話を選ぶと、保存日時・質問・回答の全文を表示します。

質問と回答の両方を対象に、入力した文字列を探します。
英字の大小と全角・半角は区別しません。空白で複数の語を区切ると、すべての語を含む会話を探します。
例：「計画 5分」は、質問か回答に「計画」と「5分」の両方が含まれる会話に一致します。
正規表現やAIによる意味検索は使いません。

「すべて表示」で検索を解除できます。結果は新しく保存された順で50件ずつ表示し、「前の50件」「次の50件」で切り替えます。
会話履歴の閲覧・検索では、記憶ファイルを変更しません。AIやGoogleへの送信も行いません。
この画面の対象は通常の会話履歴です。比較の記録・長期記憶・計画はそれぞれ従来のボタンから確認できます。
