# v0.28：調査方法の自動選択

トメリスを閉じて、いつものアイコンから開き直してください。初期設定は「自動」です。

- 天気の質問：既存の天気専用サービスを使用。
- 対象の概要・資料：Wikipedia日本語を優先。
- 最新、ニュース、価格、料金など：Braveキー設定時はBrave、それ以外はBing RSSを試行。
- 自動選択の検索で候補がない場合：別の検索方法を追加で試行。候補があっても関連本文を得られなければ未確認と表示。
- URL指定：そのURLの本文を読む既存経路を使用。

質問の先頭・末尾に方法を指定できます。
例：「Googleでアイアンマンについて調べて」「アイアンマンをWikipediaで調べて」「Braveで最新ニュースを調べて」。
指定はその質問だけに適用し、次の質問では元の設定に戻ります。指定した方法が失敗しても、他の方法へ切り替えません。

Google指定は、Geminiキー設定済みならGoogle検索付きAPIの報告を開き、未設定ならGoogleの検索画面を開きます。Bing・DuckDuckGoの指定はブラウザー検索です。ブラウザー検索結果は自動取得しません。Gemini指定はAPI専用で、キー未設定なら理由を表示します。
APIは利用枠を消費します。キーは設定画面から登録し、この起動中だけ保持します。

自動選択は質問の語句に基づくルールです。あらゆる言い回しや最適な情報源の判定を保証するものではありません。Bing RSSには無関係な結果が多い制約があるため、本文の関連性を確認できない結果から回答を作りません。
通常の調査報告の自動要約は引き続き停止しています。

検証：145件の自動テスト成功。倍率2条件で画面操作を確認。今回の経路テストは模擬応答で実施し、新たなAPIの実接続確認ではありません。旧版と既存データは保持しています。
