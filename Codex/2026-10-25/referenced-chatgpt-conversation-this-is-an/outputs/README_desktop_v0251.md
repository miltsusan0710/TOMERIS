# トメリス v0.25.1：サイト紹介でURLを生成しない

「ジャービスに関するサイトを出して」が通常会話へ進み、AIが未確認のURLを回答する不具合を修正しました。

トメリスを閉じ、アイコンから開き直して同じ質問を送ってください。「会話＋自動検索」「ネット検索」「情報収集」で、サイト・URL・リンクを求める依頼は検索結果の一覧表示に切り替わります。AIでサイト名やURLを作りません。通常の「会話」モードでは検索への切り替えを案内し、無断で検索はしません。

検索結果の見出し・抜粋にテーマ名が含まれるものから最大5件を表示し、同一URLや同一ページのアンカー違いを重複させません。リンク先の全文・公式性・正確さを検証した一覧ではありません。「ジャービス」のように複数の意味がある言葉は、分野や正式名称を追加すると対象を絞れます。

検索に失敗したり条件に合う結果がなければ、URLを補って回答しません。「そのサイト」だけではテーマを推測せず尋ねます。既存の誤った過去回答は書き換えていません。サイト紹介以外のAI回答全般の正確性を保証する修正ではありません。

112件の自動テストと一時データの画面テストで、ユーザーの質問そのものの振り分け、モデルを呼ばない処理、重複・不正URLの除外、通信失敗、クリック可能なURL表示を確認しました。今回の検索結果はテストで模擬しており、ジャービスの実サイト一覧を検証したわけではありません。

前の版を使う場合は、アプリを閉じ、outputsフォルダーで以下を実行できます。

```powershell
py -3 -B .\tomeris_desktop_v025.py
```
