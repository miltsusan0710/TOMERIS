# トメリス v0.15：7日間のまとめ

1. アプリを×で閉じて開き直します。
2. 「計画の履歴」を開きます。
3. 右下付近の「7日間のまとめ」を押します。

今日を含む直近7日間を、日本時間の日付で集計します。履歴画面の日付絞り込みとは独立しています。
各日の最後に保存した計画だけが対象です。同じ日に作り直した以前の計画は二重計上しません。

表示内容：
- 計画を保存した日数
- 完了チェックあり・チェック未完了・チェック記録なしの行動数
- 計画した時間の合計（実際の作業時間ではありません）
- 振り返りがある日数
- 各日の計画と振り返りの原文

チェック記録がない行動は、実際に完了したかどうかは不明として表示します。
AIによる評価や要約は行いません。Googleへの接続も不要です。
閲覧と再読込で、計画・記憶・完了記録・振り返りファイルを書き換えません。
