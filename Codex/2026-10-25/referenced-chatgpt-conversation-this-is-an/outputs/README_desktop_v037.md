# v0.37：話題を切り替えたときの文脈整理

確認待ちの検索方法や天気の地域が、別の操作へ混ざる問題を修正しました。

- 「Googleで調べて」の対象確認中に「計算: 2+2」と送っても、Googleを開かず計算します。
- 同じ確認待ちから天気の質問へ移った場合も、検索指定を解除して天気の地域・日付を確認します。
- 「キャンセル」で検索・天気・資料調査・地震の引き継ぎを取り消せます。記憶や保存資料は消しません。
- 「話題を変えて、計算: 3+4」のように、明示的な話題変更と新しい質問を一緒に入力できます。この場合はローカルAIへ送る直近会話の文脈も切り替えます。
- 天気を調べた後でも、新しく地域を含まない「明日の天気は？」と聞き直した場合、以前の地域を黙って再使用しません。地域確認中に「明後日は？」と変更しても、日付を保持して地域を尋ねます。
- 天気の後の「他の情報は？」を、以前の資料調査の続きと混同しません。
- 地震の後の「もっと詳しく」は同じ地震の続報確認へつなぎます。
- 明示した方法での資料調査の続きは、対象と表示済み出典の除外を保持します。
- 会話の好みや資料学習の操作へ移った場合は、以前の天気などの確認待ちを解除します。

これは対応する言い回しと処理の引き継ぎを整理する改善です。あらゆる会話の意味や話題転換を理解できるようになったというものではありません。AIモデルの再訓練は行っていません。

検証：自動テスト204件成功。上記の話題遷移を回帰テストし、会話画面でも検索確認→計算、天気確認の取消、新しい地域確認→明後日→平塚市を連続送信して確認しました。一時データと模擬応答を使い、外部サービスの実接続は行っていません。
旧版と既存の記憶・計画・資料は保持しています。開き直すとv0.37になります。
