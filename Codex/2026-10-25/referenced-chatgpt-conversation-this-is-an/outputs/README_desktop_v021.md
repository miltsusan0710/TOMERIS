# トメリス Windowsアプリ v0.21

長期記憶の修正画面で、変更前の文章を選べるようにしました。Google連携は後回しのままです。

## 操作
1. トメリスを閉じ、いつものアイコンから開き直します。
2. 「記憶を確認」で記憶を選び、「本文を修正」を押します。
3. 「以前の文章を選ぶ」で変更前の文章を選び、「本文に読み込む」を押します。
4. 本文を確認します。必要ならさらに編集できます。
5. 「修正を保存」を押すと反映されます。保存せずに閉じることもできます。

「変更前」の数字は履歴の順番です。同じ日時でも区別できます。新しい履歴から並べています。「現在保存されている文章」も選べます。変更履歴がない記憶には現在の文章だけ表示します。

読み込みだけでは保存しません。未保存の編集を別の文章で置き換える際は確認が表示されます。保存時はv0.20と同じ仕組みで、戻す前の文章も履歴に追加します。元と同じ本文なら履歴を追加しません。文字数制限や重複チェックも従来通りです。

## 保存と検証
既存のデスクトップ版データを使用します。旧プログラム・CLI版の記憶は変更しません。今回の実装・テストでユーザーの記憶を書き換えていません。画面操作にはAIやGoogleへの送信はありません。

82件の自動テストに加え、一時データを使ったTk画面テストで、履歴なし・文章の読み込み・キャンセル・未保存編集の置き換え確認・保存失敗と再試行・履歴保持・再起動・200％表示を確認しました。

前の画面を使う場合はアプリを閉じて outputs フォルダーで以下を実行できます。保存済みの本文を取り消す操作ではありません。

```powershell
py -3 -B .\tomeris_desktop_v020.py
```
