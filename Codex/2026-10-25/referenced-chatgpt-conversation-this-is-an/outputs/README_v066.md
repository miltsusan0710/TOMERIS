# トメリス v0.66：画像・音声・複数資料

いつものアイコンから再起動してください。上の「画像・音声・依頼」メニューを使います。

- 画像を選んで質問：PNG/JPEG（10MB以内）を選び、質問を入力します。gemma3:4bが導入されていれば画像用に使用します。会話モデルの設定は変更しません。画像はローカルOllamaへ送り、画像や回答を長期記憶へ自動保存しません。見間違い・文字の読み違いはあり得ます。
- 音声を入力：押した時だけマイクを使い、短い一言を聞き取ります。最大20秒で処理を停止。入力欄に文字を追加するので、確認してから普段の送信ボタンで送ってください。認識時は外部送信しませんが、後で調査として送信した質問は既存の検索先へ送られます。
- 最後の回答を読み上げ：日本語音声で読みます。1000文字まで。読み上げ中は操作待ちになります。
- 音声機能を確認：Windowsに対応する日本語音声機能があるか確認できます。
- まとめて依頼：計算式、または「調査: 対象名」を1行ずつ、最大4件まで入力します。調査と計算を振り分けて順番に処理します。例：

```
調査: アイアンマン
調査: 認知バイアス
12000の15%
```

現在は限定した依頼の振り分けです。音声・画像から勝手にPC操作をする機能や、複雑な目的を自ら分解して無制限に実行する機能ではありません。画像や音声の連続監視もしません。

「資料学習 → 自動収集のテーマ・結果」では、追加テーマ最大3件に加え標準12テーマを巡回します。取得は最大2件並列、完了から10分以上、1起動12試行まで。保存済みの同名資料は7日、失敗を含む試行は24時間空けます。再起動後も試行記録を引き継ぎます。停止設定は保持します。テーマ変更後は停止状態になるため、再開ボタンを押してください。

資料は出典付きの未検証資料です。保存によってモデル自体が訓練されるわけではありません。アプリ終了中は収集しません。巡回記録collection_rotation.jsonは現在のバックアップ対象外です（資料本文と追加テーマは既存の対象）。復元時には失敗の待機期間がリセットされることがあります。

実確認：Gemma 3 4Bを追加し、赤色のテスト画像を正しく回答。Windowsの日本語音声認識・合成を検出、合成音声の一言「こんにちは」を文字起こし。実マイク入力・スピーカー出力の確認は未実施。4テーマの実収集で3テーマ保存、1テーマは同名記事なし。Google/Braveの有効APIキー接続は未検証です。
