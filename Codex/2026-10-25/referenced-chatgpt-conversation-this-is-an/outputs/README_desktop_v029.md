# v0.29：調査の続きを会話で指定

「アイアンマンについて調べて」の結果を受けて「他の情報は？」「ほかには？」「もっと詳しく」と送ると、直前の調査対象で追加調査します。

- 通常会話に戻してローカルAIに返答させず、追加の資料取得を行います。
- 表示済みの出典URLを除外し、未表示の出典を最大3ページ確認します。同じURLへ転送された場合も重複を除きます。
- Wikipediaなど明示した方法を引き継ぎます。
- 追加の根拠が取れなければ、その旨を表示します。未取得の事実を補って回答しません。
- 調査対象と表示済みURLはこの起動中のみ保持します。別の話題へ移ると、以前の調査の続きとして扱いません。
- 起動し直した後は、最初に「アイアンマンについて調べて」から入力してください。

限界：今回は未表示の資料を追加で取得する機能です。同じ記事の未表示部分を深掘りする機能や、自動要約の再開ではありません。検索候補の範囲で追加資料がなければ、確認できなかったことを伝えます。

検証：156件の自動テスト成功。画面から「アイアンマンについて調べて」→「他の情報は？」を送信し、新しい出典が表示されることを模擬検索結果で確認しました。検索方法の画面操作も倍率2条件で確認しています。今回の修正で新たな外部API実接続テストは行っていません。
既存の記憶・計画は変更せず、以前の版を残しています。
