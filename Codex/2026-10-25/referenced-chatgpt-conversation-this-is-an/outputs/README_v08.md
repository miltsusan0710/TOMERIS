# トメリス v0.8：ローカルAIの回答比較

Geminiの設定なしで、導入済みの異なる2つのOllamaモデルへ同じ質問を送り、回答を順に表示します。自動の優劣判定はしません。v0.7のGemini切替は残していますが、/compare は選択中のAIに関係なくOllamaだけを使用します。

## 初回起動

現在のトメリスを /exit で終了し、PowerShellで実行してください。

```powershell
Set-Location -LiteralPath 'C:\Users\hiroy\Documents\Codex\2026-10-25\referenced-chatgpt-conversation-this-is-an\outputs'
py -3 -B .\tomeris_v08.py --import-memory .\tomeris_memory_v07.json
```

元ファイルを読み取り、別名の tomeris_memory_v08.json へ初回だけ複製します。既に保存先がある場合は上書きせず停止します。v0.6、v0.7と元の記憶は変更しません。2回目以降：

```powershell
py -3 -B .\tomeris_v08.py
```

## モデル確認と比較

起動後の「あなた >」に入力：

```text
/models
```

表示された正確なモデル名を2つ選んで、次の形式で入力します。MODEL_AとMODEL_Bは一覧にある名前で置き換えてください。

```text
/compare MODEL_A MODEL_B 今日の作業に集中するための工夫を3つ挙げて
/comparisons
```

モデルが1つしかない場合、2モデルの比較はまだ実行できません。自動ダウンロードやインストールはしません。同じモデル名の重複や同一digestの別名は拒否します。モデル追加前に /models の結果をチャットに貼って相談できます。

## 処理と保存

- 同じ質問と同じ記憶コンテキストのスナップショットを各モデルに渡します。先に出た回答を次のモデルへ渡しません。
- メモリー負荷を抑えるため1モデルずつ呼び出し、応答後にモデルを解放する指定を送ります。
- 既存の実行宣言・PC操作リスク回答の簡易検査を行います。問題のある回答は定型回答に置換した旨を表示します。正確性を保証する検査ではありません。比較時は品質不良による再生成をしません。
- 一方の通信失敗でも残りを試し、失敗と成功を区別します。両方失敗なら保存しません。回答の長さ上限による打ち切りも失敗として表示します。
- 回答時間は通信・モデル読込を含む参考値です。速度だけで性能を判断しません。最大待機時間は各モデル180秒です。Ctrl+Cで中止できます。中止した比較は保存しません。
- 比較はv0.8記憶ファイル内の comparisons に保存し、/comparisons で最新5件を表示します。通常会話の検索・履歴・次回AIへの記憶コンテキストには混ぜません。長期記憶へ自動採用しません。
- /pc の結果は引き続きAIへ渡さず、保存もしません。既存の通常会話・長期記憶などはv0.8専用記憶に保存します。
- /models はOllamaのローカル一覧から、クラウド用と判別できるモデルを除外します。Ollama自体はユーザー管理のサービスです。ローカルモデルとして正しく設定された通常のOllamaを前提とします。
- 通信先は127.0.0.1:11434に固定し、プロキシ環境変数とHTTPリダイレクトを使いません。共有の旧プロバイダーファイルは変更せず、新版のローカルアダプターだけで実装しています。
