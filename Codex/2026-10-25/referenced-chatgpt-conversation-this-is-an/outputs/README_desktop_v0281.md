# v0.28.1 作業報告

## 改善したこと
- 「Googleで調べて」など、方法だけ指定された場合は対象を確認し、次の入力まで指定を保持します。「キャンセル」で取り消せます。
- 確認待ちの間に別の方法が明示されたら、新しい指定を優先します。
- 「Googleではなく…」のような否定や複数の方法が混ざる指示は、最初の方法で勝手に検索せず、方法の確認を求めます。
- 「Googleでできること」のようなサービス自体についての質問を、Google検索の指示と取り違えないようにしました。
- 「公式サイトを出して」などの意図を、検索語の整形後も自動選択に反映します。
- URLだけを貼った場合にも、公開ページの本文冒頭を取得して表示します。読み取った原文と、事実確認済みの回答を区別します。
- Wikipedia指定にURLが含まれる場合、他サイトを黙って読むことを避け、検索対象名を確認します。

## 検証結果
- 自動テスト：151件成功。
- 画面操作：倍率2条件で検索方法の設定、キー消去、失敗時の案内、通常の計算への復帰を確認。
- 実接続：Wikipediaで「アイアンマン」「Ollama」の検索・本文取得に成功。修正版の自動検索でも、アイアンマンの本文と出典を表示できました。
- Google・Braveの有効なAPIキーを使用した実接続は未確認です。
- テストは一時フォルダーで実施。既存の記憶・計画データはテストに使用していません。

## 使い方
トメリスを閉じ、いつものアイコンから開き直してください。タイトルに v0.28.1 と表示されます。
普段は「会話＋自動検索」のまま質問できます。調査方法の初期設定は「自動」です。

例：
1. 「Googleで調べて」
2. トメリスから対象を聞かれたら「アイアンマン」

Googleのキー未設定時はブラウザーのGoogle検索画面を開きます。結果を自動取得した意味ではありません。そこから選んだページのURLをトメリスへ貼ると本文を読みます。

## 残る制約
自動選択は語句によるルールで、すべての表現を理解するものではありません。検索候補が見つからない場合は別の方法も試しますが、本文の関連性が不足した場合は確認できなかったことを報告します。
キーがない場合の一般Web検索は試験的なBing RSSを使用します。無関係な候補が返る制約が残っています。本文の根拠が取れない状態でAIの推測を報告にしません。
URL本文取得は公開HTML・テキストが対象です。ログインやJavaScriptが必要なサイトなどは取得できない場合があります。
以前の版は残しています。Google・Braveへの課金設定やアカウント作成は行っていません。
