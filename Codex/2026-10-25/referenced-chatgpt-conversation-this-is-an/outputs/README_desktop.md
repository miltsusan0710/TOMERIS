# トメリス Windowsアプリ v0.9

専用ウィンドウから会話・記憶確認・長期記憶の追加・PC情報・2モデル比較を操作できます。追加の有料サービスは不要です。今回はPythonがインストールされた今のPCで使う版です。単体の.exe化はまだ行っていません。

## 起動

デスクトップの「トメリス」をダブルクリックします。デスクトップにまだない場合、同じフォルダーにある「トメリス.lnk」をダブルクリックできます。VS CodeやPowerShellを開く必要はありません。Ollamaは起動しておいてください。

起動できない場合は、このフォルダーのPowerShellからエラーを確認できます。

```powershell
py -3 -B .\tomeris_desktop.py
```

起動アイコンは、このPCのPythonと現在のoutputsフォルダーへのショートカットです。Pythonやフォルダーを移動した場合は作り直す必要があります。

## 操作

- 下の入力欄に質問を書き「送信」。Enterは改行、Ctrl+Enterは送信です。
- 「この質問で記憶を参照する」を選ぶと記憶を使う質問になります。従来どおり「私の目標を教えて」は保存原文を参照します。
- 「会話」を「2モデル比較」に変更し、異なる2モデルを選んで質問を送ります。
- 左の「記憶を確認」「会話履歴」「比較の記録」「PC情報」「基本人格」で表示できます。
- 「＋ 長期記憶を追加」で分類と本文を入力し、「保存」を押した内容だけが長期記憶になります。
- 「接続を確認」でOllamaのモデル一覧を更新します。Ollamaが停止していても記憶やPC情報の表示は使えます。
- ウィンドウの×で終了します。回答中に閉じた場合は、処理・保存が終わってから終了します。AIの通信がタイムアウトするまで待つ場合があります。

GUIでは入力欄に従来のスラッシュコマンドを入力せず、ボタンを使ってください。Gemini、成長ログ追加、検索、記憶削除など、画面に用意していない操作は従来のv0.8.4で利用できます。Geminiキーはこの画面では使いません。

## 保存

初回起動時、同じフォルダーの tomeris_memory_v084.json があれば、tomeris_desktop_data/tomeris_memory.json にコピーして引き継ぎます。旧ファイルと過去版は上書きしません。以後、デスクトップ版の記憶だけを更新します。初回のコピー元がなければ空の記憶で開始します。

デスクトップ版と旧版の記憶は別々に増えます。比較記録も引き継ぎ、通常会話とは別に保存します。PC情報は画面表示のみでAI送信・履歴保存しません。二重起動はデータフォルダーのロックで防ぎます。
