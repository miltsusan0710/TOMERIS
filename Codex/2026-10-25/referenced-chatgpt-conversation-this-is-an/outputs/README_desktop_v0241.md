# トメリス v0.24.1：天気取得と地域の言い直しを修正

## 操作
トメリスを閉じて、いつものアイコンから開き直してください。

1. `今日の天気は？`
2. `平塚市`
3. 続けて `荒川区`

地域名を言い直したときも天気を取得します。前の地域の取得に失敗していても天気の話題を保持します。別の話題・計算・通常会話へ切り替えたら地域待ちを解除します。`東京都荒川区の明日の天気` のようにまとめて入力することもできます。

## 今回の修正
- 天気を一般検索から分離し、Open-Meteoの予報APIから取得します。
- 地域名を日本国内の候補と照合します。都道府県を入力した場合も照合します。同名の異なる地域が複数あれば確認を求めます。
- 荒川区は「東京都 荒川区 荒川」の代表地点を使用します。平塚市も代表地点で、市区全域・自宅の天気や観測値ではありません。
- 日本時間の予報日、天気コード、最高・最低気温、日内最大の降水確率をプログラムで表示します。AIの文章生成は使いません。
- 日付や単位が確認できないデータは表示しません。欠測は未取得と表示します。
- 失敗時も通常AIに地域名だけを送らないため、今回の「回答が未完了」エラーにつながる誤った処理経路を防ぎます。通常会話での別原因による生成失敗をすべて解決するものではありません。

## 外部送信
地域名を geocoding-api.open-meteo.com に、その地域の代表地点の座標を api.open-meteo.com に送ります。端末の現在地は取得しません。保存済みの記憶・会話は送りません。予報の取得成功時は通常の会話履歴へ保存します。天気の話題はこの起動中だけ保持します。

API資料・出典：
- https://open-meteo.com/en/docs/geocoding-api
- https://open-meteo.com/en/docs
- 地点情報はGeoNames由来、予報はOpen-Meteo。利用条件は提供元の現行条件に従います。
