# v0.36：地震の後続発表を識別番号で確認

「今の地震の震源は？」で確認した後に「その後は？」「続報は？」「地震の続報は？」と入力すると、前回と同じ気象庁の地震識別番号（EventID）の電文だけを探します。
別の地震の新しい発表があっても、前回の地震の続報として表示しません。

- 震度速報で震源が未掲載なら未確認と表示。
- 同じ地震の震源情報・訂正を取得したら、今回の電文の内容を表示。
- 取消の場合は取消と明記し、以前の震源を有効な情報として再表示しない。
- 前回より古い発表、訓練・試験、識別番号不明、古い対象時刻は使用しない。
- 同じ電文なら「新しい発表は取得していません」と表示。
- 通信失敗や対象電文が見つからない場合、古い記録や別の地震で補わない。

対象の記録はこの起動中だけ保持し、別の話題へ移ると解除します。質問されたときだけ取得し、自動ポーリング・通知・警報は行いません。
確認範囲は高頻度フィードの最新側最大6電文です。配信一覧は10分以内、発表・地震の対象時刻は15分以内という保守的な条件を維持しています。対象が掲載範囲にない場合や時間が経った場合は未確認になります。
津波情報・避難判断・利用者が感じた揺れとの一致を保証する機能ではありません。

検証：自動テスト195件成功。識別番号一致、別地震の除外、震源情報・訂正・取消、古い発表への逆戻り拒否、訓練・不明ID・古い発生時刻、最大取得数、話題変更、通信失敗を模擬電文で確認しました。
会話画面から「今の地震」→「その後は」→取消→別の話題を操作して確認しました。今回の新しい追跡処理について外部APIの実接続は行っていません。旧版と既存の記憶・計画を保持し、一時データで検証しました。

開き直すとv0.36になります。
