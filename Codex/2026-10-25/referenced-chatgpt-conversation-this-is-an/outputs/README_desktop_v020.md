# トメリス Windowsアプリ v0.20

長期記憶の検索と本文修正を追加しました。Google連携は後回しのままです。

## 使い方
1. 起動中のトメリスを閉じ、デスクトップの「トメリス」から開き直します。
2. 左の「記憶を確認」を押します。
3. 分類・本文・記憶IDを検索できます。空白区切りはすべての語を含む検索です。50件ずつ表示します。
4. 記憶を選んで「本文を修正」を押し、文章を編集します。
5. 「修正を保存」を押すと反映されます。「閉じる」で未保存の変更を破棄できます。
6. 記憶を選ぶと現在の本文と変更前の文章を確認できます。

本文は1〜10000文字。分類・重要度・IDは維持します。本文が同じなら履歴を追加しません。他の記憶と同じ本文、空欄、開いた後に変更された記憶の保存は拒否します。

## 保存と互換性
デスクトップ版の既存の tomeris_desktop_data/tomeris_memory.json を利用します。修正時だけ対象の本文を変更し、同じ記憶に edit_history と更新日時を追加して一度に保存します。保存エラー時はメモリ内の変更も戻します。元のCLI版や過去のプログラムは変更しません。
検索・修正はAIを呼びません。記憶を使う会話では現在の本文が対象で、変更前の文章は記憶コンテキストに追加しません。過去の会話に記録済みの文章は書き換えません。
変更履歴は既存のバックアップ機能で記憶ファイルと一緒に保存されます。起動時のモデル設定は従来通り別ファイルで、バックアップ対象外です。

## 検証
一時データで82件の自動テストが成功。検索、修正履歴、再起動、古い編集の拒否、重複拒否、保存失敗時の保護を含みます。
実際のTk画面で検索・編集・保存失敗と再試行・キャンセル・再起動を確認し、200％拡大時のボタン配置も検証しました。ユーザーの実データはテストに使っていません。

前の画面に戻す場合は、アプリを閉じて outputs フォルダーで次を実行します（本文の修正を取り消す操作ではありません）。

```powershell
py -3 -B .\tomeris_desktop_v019.py
```
