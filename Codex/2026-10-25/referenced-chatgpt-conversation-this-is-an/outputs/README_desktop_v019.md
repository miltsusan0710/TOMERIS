# トメリス v0.19：起動時の会話モデルを保存

1. トメリスを×で閉じ、デスクトップのアイコンから開き直します。
2. 画面上部のモデル欄で、普段使いたいモデルを選びます。
3. 「データ」→「選択中の会話モデルを起動設定に保存」を押します。
4. 保存完了の表示を確認し、アプリを閉じて開き直します。
5. 保存したモデルが選択されていることを確認してください。

モデルを選ぶだけなら、その起動中の一時的な切り替えです。メニューから保存したときだけ次回の起動設定が変わります。
設定の対象は会話モデルです。起動モードは従来どおり「会話」で、記憶参照はオフから始まります。
比較用の2つ目のモデルは、導入済みの異なるモデルから選びます。

保存したモデルが見つからない場合は、使用可能なモデルを選び、お知らせを表示します。保存設定自体は変更しません。
Ollamaへ接続できない場合は、接続確認が成功したときに保存済みの設定を適用します。
設定ファイルが読めない場合もアプリを起動でき、標準の選択で続けます。

## 保存先とバックアップ

設定はデータフォルダー内の `desktop_settings.json` に保存します。
会話・記憶・計画のファイルは変更しません。
現在の「記憶・計画のバックアップ」はこの起動設定ファイルを含みません。別フォルダーに復元した場合、必要に応じてモデルを選び直して保存してください。
