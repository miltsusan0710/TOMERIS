# v0.30.1：現在地の誤回答を防止

現在のトメリスには位置情報を取得する機能がありません。「現在地」に対して、以前の会話の地域名を現在地として回答しないよう、AI生成を通さず未取得であることを案内します。

「明日の天気は？」→「現在地」では、市区町村の入力を案内し、「明日」の条件を保持します。続けて「平塚市」と入力すると、平塚市の明日の予報を取得します。

確認：自動テスト160件成功。上記の会話を実際の画面から送信し、地域が未指定の間は天気APIを呼ばず、地域指定後に「平塚市」「明日」が渡ることを模擬APIで確認しました。新たな位置情報取得や外部サービスの実接続は行っていません。

トメリスを閉じて開き直してください。タイトルの v0.30.1 が目印です。デザイン、記憶・計画データは維持します。
