# トメリス v0.13：残った行動を今日へ引き継ぐ

1. トメリスを×で閉じ、デスクトップのアイコンから開き直します。
2. 「計画の履歴」で引き継ぎ元の計画を選びます。
3. 「残った行動を今日の下書きに」を押します。
4. 内容と時間を確認・修正します。不要な行動は入力欄を空にして除けます。
5. 「この内容を保存」を押すと、今日の新しい計画として保存されます。

下書きを開くだけでは保存しません。×で閉じれば取り消せます。
完了チェックが付いた行動は除外します。チェック記録がない計画は全行動を下書きに入れ、その旨を表示します。すべて完了している場合は下書きを作りません。
使える時間の初期値は、引き継ぐ行動の合計時間です。今日の都合に合わせて変更してください。
今日すでに計画がある場合、新しく保存したものが「今日の計画」に表示されます。以前の計画は履歴に残ります。
元の計画と完了記録は変更しません。新しい計画の完了チェックは未完了から始まります。
Google接続やAI生成は不要です。
