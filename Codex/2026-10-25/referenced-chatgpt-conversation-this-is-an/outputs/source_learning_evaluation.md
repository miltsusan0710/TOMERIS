# 資料学習の比較検証

同じ8つの質問・検索結果を、資料再利用なし／ありで比較しました。一時データと固定した模擬ページを使用し、ネットやAIの自己採点は使っていません。

|条件|根拠を表示できた件数（なし→あり）|本文取得の試行数（なし→あり）|
|---|---:|---:|
|検索が正常|1 → 1|1 → 1|
|検索候補が空・既知の出典は取得可能|0 → 1|0 → 1|
|無関係な候補・既知の出典は取得可能|0 → 1|1 → 2|
|保存出典も取得失敗|0 → 0|0 → 1|
|無関係な保存資料|0 → 0|0 → 0|
|最新情報に保存資料を使わない|0 → 0|0 → 0|
|同じ出典の重複|1 → 1|1 → 1|
|明示したWikipedia指定を保持|0 → 0|0 → 0|

この固定シナリオでは、根拠を表示できた条件は2/8 → 4/8でした。本文取得の試行は合計3 → 6回です。

## 確認したこと

- 検索候補が欠けても、関連する出典を保存していれば再取得で補える場合があります。
- 取得に失敗した出典の保存文を、今回の根拠として使い回しません。
- 無関係な保存資料・最新情報の質問・指定した検索方法に反する資料は追加しません。
- 表示した重複出典は全条件で0件でした。

## 限界

この結果は模擬ページを使った機能検証です。実際のWebでの正答率、検索品質、アクセス成功率、速度向上、モデル能力の成長を証明するものではありません。ページ内容が事実かどうかの評価も行っていません。
資料再利用によりアクセス回数が増える場合があります。JSONに記録した実行時間はローカル試験処理の時間であり、実際のネット応答時間ではありません。学習ありの方が速いとは結論づけません。
