# トメリス v0.27：複数の調査方法

## 起動と使い方
トメリスを閉じ、いつものアイコンから開き直してください。
上部の「調査方法・Google検索」を開くと、検索する文章と方法を選べます。

- キーなしでGoogleを使う：「検索・確認」で検索文を入れ、「Googleで開く」。ブラウザーで結果を確認し、調べたいページのURLをトメリスの会話欄へ貼ってください。検索結果の自動取り込みではありません。
- 自動の資料取得：初期設定はWikipedia日本語です。会話欄で「アイアンマンについて調べて」と入力できます。
- 複数の提供元を使う：「設定・APIキー」で「併用（Wikipedia＋Brave）」を選び、自分のBrave APIキーを入力して「この設定を使う」。一方が失敗しても、もう一方の結果と失敗理由を表示します。
- Googleの検索付きAI回答：自分のGemini APIキーと利用可能なモデルIDを設定し、「Google APIで調べて表示」を押します。現在の質問だけを送り、生成した報告をブラウザーで開きます。通常の資料報告とは別の機能です。

APIは利用枠を消費し、契約によって料金が発生する場合があります。キーをチャットに貼らないでください。
設定とキーはこの起動中だけ保持します。キー欄が空欄の場合は現在のキーを維持します。「APIキーを消去」で両方を消せます。

検証は一時データで実施し、通常の記憶・計画をテストに使用していません。

## 報告の範囲
Wikipediaは百科事典であり、Web全体の検索ではありません。幅広いWeb検索にはブラウザー検索、またはキーを設定したBraveを使います。
通常の調査報告は最大3ページから対象語を含む原文を提示します。以前の誤要約を避けるため、ローカルAIによる資料要約は停止したままです。原文の取得は、その記述が正しいことの証明ではありません。
Google APIの回答はGoogle側AIが作成する別の報告で、トメリスで裏取り済みとは表示しません。Googleブラウザー検索と同じ順位・結果になる保証はありません。
ログイン、JavaScriptが必要なページ、PDFなどは、現在の本文取得の対象外です。あらゆるサイト・方式を網羅したものではありません。

Google APIの報告HTMLはデータフォルダー内の google_reports に保存します。質問と回答を含み、キーは保存しません。このフォルダーは現在の通常ZIPバックアップには含まれません。
旧版ファイルを残し、同じデータフォルダーを引き続き使用します。戻す場合は起動用 tomeris_desktop.py の読み込み先を tomeris_desktop_v0261 に変更します。
