# v0.31：会話を中心にした配置

トメリスを閉じ、いつものアイコンから開き直してください。タイトルの v0.31 が目印です。

- 上の円形表示を小さくし、会話欄を広くしました。
- 会話モード・モデル選択は「表示」→「会話設定を表示」から開けます。
- 「表示」→「左メニューを表示」のチェックを外すと、会話欄の横幅も広がります。
- 入力欄は「入力欄を広げる／縮める」で2行・4行を切り替えられます。入力中の文章は保持します。
- 会話の初期文字サイズを13にし、行間と発言間の余白を調整しました。「小」「大」で変更できます。
- 「最新へ」で会話の末尾へ移動できます。「回答コピー」も利用できます。

検証：1120×850の画面で、会話欄の高さが415→534ピクセル、別倍率では271→405ピクセルに拡大。倍率2条件と880×760の小さい画面で、入力・送信・会話欄が収まることを確認しました。左メニュー切替、会話設定と比較モデル表示、入力欄拡縮、文字サイズ変更も確認。
会話画面からの調査→追加調査、および明日の天気→現在地→市区町村の動作は模擬応答で確認済みです。
検索・AI処理や既存の記憶・計画データの形式は変更していません。旧版も残しています。
