# トメリス Windowsアプリ v0.22

会話欄の上に「最後の回答をコピー」ボタンを追加しました。

## 使い方
1. トメリスを閉じ、いつものアイコンから開き直します。
2. 質問を送信し、回答を待ちます。
3. 「最後の回答をコピー」を押します。
4. メモ帳などで Ctrl+V を押して貼り付けます。

コピーするのは、この起動中に会話欄へ最後に「トメリス」として表示された本文です。計画などの表示結果・保存完了メッセージも含みます。質問・「お知らせ」・起動時の挨拶は対象外です。回答がまだないとき、処理中、終了中はボタンが無効になります。別窓の検索結果は対象外です。

コピーはボタンを押したときだけ行い、クリップボードの内容を置き換えます。AIへの送信、記憶や会話履歴の更新は行いません。Google連携は後回しのままです。

## 検証
専用の一時データを使い、Tk画面で最新の本文・日本語・改行・絵文字の引き渡し、質問やお知らせの除外、コピー失敗時の表示、処理中の禁止、ボタン位置、記憶ファイルが変わらないことを確認しました。テスト中はユーザーのクリップボードを変えないようコピー処理を模擬しました。実際の他アプリへの貼り付けは、上の手順で確認してください。

既存のデータと過去版を保持しています。前の版を使う場合はアプリを閉じて outputs フォルダーで実行してください。

```powershell
py -3 -B .\tomeris_desktop_v021.py
```
