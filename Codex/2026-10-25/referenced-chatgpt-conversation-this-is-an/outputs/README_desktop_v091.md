# トメリス デスクトップ v0.9.1

「今日の計画」を追加しました。既存のデスクトップアイコンで起動できます。

## 使い方

1. 起動中のトメリスを右上の×で閉じます。処理中は終了まで待ちます。
2. デスクトップの「トメリス」を開きます。タイトルが v0.9.1 になったことを確認します。
3. 左の「計画を作る」を押します。
4. やりたいことと使える時間（分）を入力します。
5. 「AIに提案してもらう」を押すか、行動を手入力します。
6. 行動と時間を確認・修正し、「この内容を保存」を押します。
7. 「今日の計画」で保存内容を確認します。閉じて開き直した後も表示できます。

例：やりたいこと「トメリスの使い方を試す」、使える時間「30」。

行動は1〜3個、時間は1分以上、合計は使える時間以内にします。空欄の行動は保存しません。
提案は自動保存しません。AIは行動を実行しません。計画作成時にAIへ渡すのは目標と時間だけで、記憶や過去会話は送りません。
AIの提案が失敗しても手入力できます。保存失敗時は入力を残します。

## 保存先と旧版

計画は `tomeris_desktop_data/daily_plans.json` に独立して保存します。
同日の保存も追記し、画面には当日の最新の計画を表示します。日付は日本時間です。
会話と長期記憶の保存先は従来どおりです。旧CLIの記憶ファイルは変更しません。
v0.9の画面コードは `tomeris_desktop_v09.py` に保存しました。

PowerShellから起動する場合：

```powershell
Set-Location -LiteralPath 'C:\Users\hiroy\Documents\Codex\2026-10-25\referenced-chatgpt-conversation-this-is-an\outputs'
py -3 -B .\tomeris_desktop.py
```

旧v0.9を使う場合はアプリを閉じてから：

```powershell
py -3 -B .\tomeris_desktop_v09.py
```
