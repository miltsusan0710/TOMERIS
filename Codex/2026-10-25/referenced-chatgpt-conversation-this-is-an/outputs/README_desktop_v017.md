# トメリス v0.17：バックアップの確認・別フォルダーへの復元

## 使い方

1. アプリを×で閉じ、デスクトップのアイコンから開き直します。
2. 上部の「データ」→「バックアップを確認・別フォルダーに復元…」を選びます。
3. トメリスで保存したバックアップZIPを選びます。
4. 検査結果、作成日時、含まれるデータを確認します。
5. 「保存先を選んで別フォルダーに復元」を押し、新しいフォルダーを置く場所を選びます。
6. 指定した場所の中に `tomeris_restored_...` という新しいフォルダーを作ります。
7. 必要に応じて「復元したデータで開く」を押し、別ウィンドウで内容を確認します。

## 元のデータとの関係

現在使用中のデータは上書きしません。復元するたびに新しいフォルダーを作ります。
復元したデータを開いたウィンドウには、タイトルに「別データ」と表示し、会話欄にも保存先を表示します。
そのウィンドウで作成・変更した内容は、復元フォルダーに保存します。
通常のデスクトップアイコンは、引き続き元のデータを開きます。今回の操作では常用するデータの切り替えは行いません。
復元したデータを後日開く場合は、データフォルダーを指定できます。

```powershell
# <復元フォルダーの実際のパス> は画面に表示されたパスに置き換えてください。
py -3 -B .\tomeris_desktop.py --data-dir '<復元フォルダーの実際のパス>'
```

## 対象と検査

トメリスv0.16以降が作成した、形式バージョン1のデータバックアップに対応します。
記憶、作成済みの計画、完了チェック、振り返りを復元します。
Google接続情報、アプリ本体、AIモデル、人格・外部知識ファイルは対象外です。アプリとモデルなどは現在のPC側のものを利用します。

ファイル名、重複、サイズ、圧縮形式、JSONの基本形式、保存時のサイズ・SHA-256との一致を検査します。
ZIPのパスをそのまま展開する処理は使わず、許可した4つのデータ名だけを書き出します。
検査画面を開いた後にZIPが変更された場合は、復元を拒否します。
これらは破損や内容の不一致を調べる検査であり、作成者の本人確認や電子署名の検証ではありません。

破損・改変・パス逸脱・重複名・リンク項目・サイズ超過の拒否、元データの保持、復元ファイルのバイト単位の一致、復元した計画・完了チェック・振り返りの読み込みを確認しました。
画面テストで検査・取消・新規フォルダーへの復元・別ウィンドウへ渡す起動引数を検証しました。別ウィンドウ起動はテスト内では置き換え、実利用データを開いていません。
