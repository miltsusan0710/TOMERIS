# トメリス v0.25：明るい球体デザインと読みやすい会話

アプリを閉じ、いつものトメリスのアイコンから開き直してください。

## 変更点
- 参考画像の球体とリングを、淡い水色・明るい青灰色の画面に取り入れました。球体は画像生成サービスを使わず画面内で描画します。
- 会話を広い白い領域に表示し、あなたの発言だけ淡い水色の背景にしました。
- 文字の色、行間、発言ごとの余白を整えました。
- 会話欄上の「小」「大」で、会話と入力欄の文字サイズを10〜18ポイントに変更できます。この起動中のみの設定です。
- 入力欄に「メッセージ」の見出しを付け、右側に送信ボタンを配置しました。
- 通常は2つ目のモデル欄を隠し、「2モデル比較」を選んだときだけ表示します。
- 使い方は上部の「使い方」メニューから確認できます。
- 画面が小さいときは球体と入力欄の高さを調整して会話領域を確保します。
- 処理中はリングの一部がゆっくり動きます。音声入力・音声再生の状態を示すものではありません。

会話・検索・計算・天気・記憶・計画の処理は従来通りです。保存済みの記録は変更していません。

## 検証
一時データの実画面で、100％・200％相当の文字拡大、通常サイズと小さいウィンドウ、会話の文字サイズ変更、入力と送信、比較欄の表示切り替え、計算応答、記憶画面を確認しました。球体のタイマーは画面終了時に停止します。画面プレビューは実データを含まないサンプル会話です。

前のデザインを使う場合はアプリを閉じ、outputsフォルダーで次を実行できます。

```powershell
py -3 -B .\tomeris_desktop_v0241.py
```
