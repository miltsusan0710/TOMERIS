# トメリス Windowsアプリ v0.24

会話のつながり、計算、情報収集を強化しました。デスクトップのアイコンから開き直すと新しい版になります。

## 試す順番
普段通り入力してください。初期モードは「会話＋自動検索」です。

1. `今日の天気は？` → 地域を尋ねられたら `荒川区`
   直前の天気の質問と地域名を組み合わせて検索します。検索結果が不十分なら取得できないと表示します。場所を長期記憶から推測しません。
2. `計算: (1200 + 800) * 1.1`
   `2200` を計算処理で求めます。
3. `12000の15%`
   `1800` を求めます。
4. `調査: Ollama`
   `Ollama`、`Ollama 公式`、`Ollama 注意点` の3つの検索語で調べます。上部の「情報収集」モードを選んでテーマだけ入力することもできます。
5. 通常の会話で質問した後、`それを短く説明して` のように続けます。
   この起動中の直前2往復をローカルAIへ渡します。回答の正確さはモデルに依存します。

## 会話と地域の引き継ぎ
直前2往復は各質問600文字・回答1200文字を上限に利用します。古い保存済みの会話を自動で読み戻すわけではありません。再起動すると、この短期の文脈は空になります。長期記憶参照は従来のチェックボックスで指定します。
地域を尋ねた直後の `荒川区`、`荒川区です`、`東京都荒川区` 等を天気の地域として受け取ります。話題を変えた場合は地域待ちを解除します。すべての表現や外国の地名には対応していません。新しい地域の質問は地域名を含めた完全な質問でも送れます。

## 計算
整数・小数・四則演算・括弧・整数の累乗に対応します。`×`、`÷`、`^` も使えます。プログラムのevalは使わず、数式の構造を読み取って許可した演算だけ計算します。端数は分数で正確に保持し、表示する小数が丸められる場合は「約」と正確な分数を示します。
式200文字以内、数値40桁以内、累乗指数-100〜100、式の複雑さと結果の大きさにも上限があります。関数・連立方程式・単位換算・自然文の文章題は専用計算機能の対象外です。「計算:」を付けた不正な式をAIの推測で答えることはしません。自然な日本語の計算依頼は、対応する数式にして入力してください。

## 情報収集
質問からテーマを取り出し、テーマそのもの・公式・注意点の3検索を順に行います。最大8件、同じホストから最大2件を表示し、完全に同じURLは重複させません。「公式」を検索語に含めただけで、結果を公式情報と保証しません。
結果の見出しと抜粋をローカルAIが整理します。AIが使えなくても取得した抜粋とURLを表示します。取得できない検索語があるときは、それを明記します。

BingのRSS検索を使った試験機能です。正式な検索APIではなく、結果が不適切な場合や利用できなくなる場合があります。複数の検索サービスを横断したり、ページ全文を読んだりする機能ではありません。更新日時・正確さ・情報源の独立性を確かめた調査ではありません。検索の抜粋だけで判断できない事項は未確認として扱います。モデル自体は変更していないため、高度な推論が常に正しくなるわけではありません。

## 外部送信と保存
検索先へ送るのは入力した質問・テーマと補助語です。天気の地域確認では直前の天気の質問と入力した地域名を組み合わせます。保存済みの記憶・会話履歴・PC情報は検索先へ送りません。短期の会話文脈はローカルOllamaにのみ渡します。
通常の回答・計算成功・取得できた調査結果は既存の会話履歴へ保存します。自動で長期記憶には登録しません。短期文脈や地域待ちはファイルに追加保存しません。ユーザーが書いた質問・テーマに個人情報が含まれる場合は、その内容も検索先へ送られます。

## 検証
101件の自動テストに成功。地域の引き継ぎ、話題変更、計算精度・コード拒否・上限、直前会話の受け渡し、検索時の記憶非送信、出典重複の整理、部分的な検索失敗を確認しました。
実際のTk画面で自動モード、天気の2ターン、計算、情報収集、通常会話の文脈を検証しました。外部検索とモデル応答は一時データで模擬しています。実モデルの回答品質や最新の天気取得成功を保証するテストではありません。今回、ユーザーの実データを書き換えていません。
