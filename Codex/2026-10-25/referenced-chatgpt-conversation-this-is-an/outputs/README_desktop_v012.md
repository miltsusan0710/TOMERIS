# トメリス v0.12：計画の履歴

## 使い方

1. 起動中のトメリスを×で閉じ、デスクトップのアイコンから開き直します。
2. タイトルが v0.12 であることを確認します。
3. 左の「計画の履歴」を押します。
4. 一覧から計画を選ぶと、全文と完了状況が表示されます。
5. 上の日付欄から、確認したい日だけに絞れます。

日付と保存順で新しい計画から表示します。同じ日に作り直した計画も、それぞれ「1件目」「2件目」のように残ります。「最新」はその日で最後に保存した計画を指します。
完了チェックの記録がない計画は「チェック記録なし」と表示します。実際に作業を終えたかどうかは、この情報だけでは判断しません。

履歴は閲覧専用です。今日の最新の計画のチェックを変更する場合は、この画面を閉じて「今日の計画」を開いてください。
Google連携の設定は不要です。Google連携は保留のまま使えます。

## 保存データと旧版

履歴の表示は、既存の計画と完了記録を読み取ります。新しいデータファイルの作成や移行はありません。
会話・記憶・計画・完了記録を保持しています。
v0.11の画面コードは `tomeris_desktop_v011.py` に残しています。
