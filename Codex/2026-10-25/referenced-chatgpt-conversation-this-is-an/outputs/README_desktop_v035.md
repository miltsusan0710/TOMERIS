# v0.35：保存資料を検索・管理

「資料学習」→「保存資料を検索・管理…」から開きます。
タイトル・URL・保存時の抜粋を検索し、選択した資料のURL、取得日時、原文抜粋を確認できます。全資料を未検証として表示します。

「URLを再取得して確認」は、選択したURLだけを既存の公開ページ取得処理で読み直し、成功／失敗と確認時刻を表示します。成功しても内容の一致・正確さを保証しません。保存時の抜粋や取得日時は更新しません。確認状態はこの起動中だけ保持します。資料学習を停止していても、明示的な再取得操作は利用できます。

「選択資料を消去」は確認後、その1件だけを保存資料から消します。通常の会話・記憶・計画は消しません。後で再調査すると同じ出典が再び保存される場合があります。一覧表示後に資料が変更されていれば、古い選択による消去を拒否して読み直しを求めます。

通常起動時の資料読み込みと保存にも、バックアップと同じ形式・URL・日時・件数・容量検証を適用しました。不正なファイルがあれば元ファイルを保持して資料学習を停止します。
v0.34の資料込みバックアップ・別フォルダー復元を引き続き利用できます。

検証：自動テスト187件成功。検索、個別消去、変更後の古い選択、保存失敗で元ファイルと一覧が維持されること、取得成功／失敗で原文を変更しないこと、不正ファイル保持、最新サービスでのバックアップを確認。
画面は倍率2条件・640×580で、検索・選択・再取得の成功／失敗・消去キャンセル／実行・通常会話への復帰を確認しました。ネット取得は模擬応答で検証し、新たな外部API実接続は行っていません。すべて一時データで確認しました。
